# 5주차 · 미션 3 — 추가 기능 구현 (바이브코딩) · 온프레미스 실행

## 1. 실행 (노트북 = 온프레미스 서버 한 대)

```bash
cd tube-lite
.venv\Scripts\activate
set PYTHONUTF8=1
# 원본 데이터가 있으면 먼저 서버를 끄고 지운다 (seed 는 누적됨)
del data.db data.db-wal data.db-shm
python seed.py          # 동영상 12개(카테고리·#태그 포함) + kim 의 재생목록 2개
python app.py           # http://localhost:5000
```

화면을 고쳤다면 `cd frontend && npm install && npm run build` (빌드 결과 `static/app/` 에 이미 반영해 둠).

## 3. 바이브코딩에 쓴 프롬프트 (재현용)

> tube-lite 는 `features/<이름>/api.py` 를 자동 등록하고, 기능은 파일·데이터를 `core/` 로만 쓴다.
> 이 규칙을 지키면서 ① `core/search.py` 조각과 `features/search` (업로드 날짜·길이·카테고리 필터, 관련성·날짜·조회수·좋아요 정렬, #해시태그) ② 비로그인 시청 기록(localStorage, 로그인 시 서버로 병합) ③ `features/playlists` (나중에 볼 동영상 포함, 공개/비공개) 를 추가해 줘.
> `app.py` 와 `App.jsx` 는 고치지 말고, 프론트는 `frontend/src/features/<이름>/routes.jsx` 로 붙여 줘.

## 4. "서버가 꺼지면 사라지는 것" 에 추가된 항목 (다음 주 해부용)

- `data.db` 의 **playlists 테이블** → 7주차 DynamoDB 에서 자동 해결
- 검색은 매번 `data.db` 전체를 읽어서 점수를 매김 (영상이 많아지면 느려짐) → OpenSearch 로 뺄 이유
- 비로그인 시청 기록은 **서버가 아니라 브라우저**에 있으므로 서버가 꺼져도, 여러 대가 되어도 남는다
